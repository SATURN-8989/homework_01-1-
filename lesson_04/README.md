# Практическая работа по дисциплине Информационные технологии
## Тема 04 Первоначальная настройка и развертывание системы веб аналитики Google Analytics 4 (GA4)

### 1 Теоретические основы и архитектура сбора данных в GA4
* **Назначение системы** Google Analytics 4 представляет собой современную систему веб аналитики позволяющую отслеживать источники трафика поведение пользователей на веб ресурсе и фиксировать ключевые действия от момента перехода по ссылке до отправки целевой заявки
* **Событийная модель учета** В GA4 абсолютно все взаимодействия пользователя с сайтом обрабатываются и передаются серверу как события (events) Часть событий собирается автоматически благодаря функции улучшенной статистики (Enhanced Measurement) включая просмотры страниц page_view прокрутку страниц до 90% и клики по исходящим ссылкам click 
* **Иерархическая структура контейнеров** Служба GA4 разделена на три строго зависимых уровня управления: Account (Аккаунт владельца) Property (Ресурс конкретного проекта) и Data Stream (Технический поток данных с веб сайта)

### 2 Пошаговый маршрут развертывания персонального веб потока
Для успешной интеграции аналитики под будущую курсовую работу был пройден следующий пошаговый алгоритм конфигурации платформы:

* **Шаг 1 Авторизация в сервисе** Осуществлен вход на официальный портал аналитики по адресу analytics google com с использованием персонального Google аккаунта администратора
* **Шаг 2 Создание рабочего ресурса Property** Внутри существующего организационного аккаунта запущено построение нового ресурса Заданы ключевые параметры отображения показателей в отчетах:
  * **Property Name (Название ресурса)** SATURN_89 Analytics
  * **Reporting time zone (Часовой пояс)** Россия · Москва GMT+03:00 (задает точные календарные границы суток при учете ночных переходов)
  * **Currency (Валюта отчетов)** Russian Ruble (RUB)
* **Шаг 3 Указание сведений о компании Business Details** Указаны базовые классификационные сведения о проекте Выбрана сфера деятельности компании в Industry Category и отмечен масштаб организации в поле Business Size как небольшая компания (1-10 сотрудников)
* **Шаг 4 Настройка параметров источника данных Web Stream** В качестве платформы сбора данных выбран пункт Web и заполнены уникальные технические параметры целевого интернет ресурса:
  * **Website URL** Указан точный протокол безопасности https и персональное доменное имя сайта saturn89-shop.ru
  * **Stream Name (Название потока)** Понятное внутреннее имя источника: SATURN_89 Web Stream
  * **Enhanced Measurement (Улучшенная статистика)** Функция оставлена в активном включенном состоянии для автоматического перехвата базовых событий браузера
* **Шаг 5 Генерация Measurement ID** Платформа успешно сформировала карточку сведений о веб потоке Web Stream Details и сгенерировала уникальный технический идентификатор потока данных
