# Лабораторная работа по Теме 09: Развёртывание автоматической маркетинговой воронки в Instagram через ManyChat

### Выполнил: student

## Цель работы:
Проектирование и запуск автоматического чат-бота для обработки входящих лидов в социальной сети Instagram с интеграцией сквозных UTM-меток для последующей фиксации переходов в СУБД и системах аналитики.

## Выполненные шаги:
1. Создана учётная запись разработчика на платформе ManyChat и произведена интеграция с профессиональным бизнес-аккаунтом Instagram.
2. Спроектирован триггер входящего потока (Post comment trigger) реагирующий на кодовое слово "LINK" под целевой публикацией.
3. Настроена двухэтапная цепочка автоматических ответов в Директ (DM Automation) с призывом к действию.
4. В финальную кнопку перехода "Open" интегрирована целевая ссылка на веб-ресурс Vercel, размеченный UTM-метками источника (`utm_source=instagram&utm_medium=manychat`) для корректного трекинга трафика.
5. Произведён успешный запуск конвейера в продуктивную сеть (Go Live).

## Результаты работы:
Интерфейс настроенной воронки и метрики успешного запуска бота зафиксированы в контрольном артефакте "смотрите папку screens".
