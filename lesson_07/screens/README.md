# Лабораторная работа по Теме 07: Создание базы данных лидов на Google Sheets и интеграция через Apps Script

### Выполнил: студент курса по Информационным технологиям

## Цель работы:
Создание структурированной таблицы для накопления заявок с веб-ресурса, настройка строгих правил валидации данных и интеграция через облачные скрипты Google Apps Script.

## Выполненные шаги:
1. Создана электронная таблица с именем `GA4 Analytics Lab — Leads`, в качестве корневого листа задан лист `leads`.
2. Сформирована структура из 9 обязательных столбцов для сбора лидов и UTM-меток, первая строка с заголовками жестко закреплена на экране.
3. Для столбца `status` настроена строгая проверка данных (Data Validation) с выпадающим списком из 4 вариантов: `new`, `in_progress`, `done`, `rejected`.
4. В редакторе Apps Script написан и сохранен серверный обработчик `doPost(e)` для автоматического приема и построчного добавления заявок в таблицу.

## Результаты работы:
Все три контрольных артефакта (структура таблицы, проверка статусов и код скрипта) успешно сохранены в репозитории в папке `lesson_07/`.
