# Лабораторная работа по Теме 08: Автоматическая очистка и подготовка данных (ETL) в Google Sheets

### Выполнил: студент курса по Информационным технологиям

## Цель работы:
Изучение принципов построения конвейеров обработки данных (ETL), проектирование автоматических правил очистки грязных логов и создание системы динамического контроля структуры полей.

## Выполненные шаги:
1. Создан рабочий документ «leads_cleaning» с раздельными листами для исходного грязного датасета (source), очищенного реестра (leads_clean) и контроля валидации (check).
2. На базе функций ARRAYFORMULA, СЖПРОБЕЛЫ, СТРОЧН, SPLIT и LET развёрнуты 9 сквозных правил для автоматического удаления лишних пробелов, нормализации текстовых регистров, фильтрации дефектных временных меток и парсинга UTM-меток.
3. На листе «check» реализован встроенный датчик структуры данных на основе массива LET для автоматической сверки текущих заголовков с контрактными требованиями.
4. Проведено стресс-тестирование системы путём импорта расширенной выгрузки данных версии v2. Новые строки обработаны и очищены в полностью автоматическом режиме.

## Результаты работы:
Контрольные артефакты формул очистки, матрицы контроля структуры и финального массива данных v2 успешно зафиксированы в репозитории `lesson_08/screens/`.
